# kynetic-renderer

This is the renderer for use with JSON documents generated by the cloud-based editor.

## Features

- Convert JSON project definitions into rendered video with `handanim`
- Supports standard drawables: `Text`, `Square`, `Rectangle`, `Line`, `Polygon`, `SVG`.
- Supports basic animations: `TranslateTo`, `FadeIn`, `FadeOut`, `ZoomOut`, `Sketch`.
- Dockerized Python rendering pipeline.

## How to use

### Docker (recommended)

You can either pull the container from Docker Hub or build the container locally.

#### Pull from Docker Hub

Pull the container from Docker Hub:
```bash
docker pull hamdivazim/kynetic-renderer:latest
```

#### Build locally
- Set your working directory to the location of `Dockerfile`.
- Run this command to build:
```bash
docker build --no-cache -t kynetic-renderer:latest .
```

#### Render a project

- Set your working directory to the location of your project file.
- Render a project:
```bash
docker run --rm -v "$(pwd)/:/input" -v "$(pwd)/:/output" kynetic-renderer:latest /input/<project file>
```
This renders a project into the same directory as the project file.
- Render a project to custom output directory:
```bash
docker run --rm -v "$(pwd)/<location of project file>:/input" -v "$(pwd)/<location for output>:/output" kynetic-renderer:latest /input/<project file>
```

#### Troubleshooting

- Output file is missing - If the logs say "Render Complete" but you don't see a file:

    * Ensure the absolute path to your project is correct. In Docker, `$(pwd)` maps your current terminal directory. If your JSON is in a subfolder, you must map that subfolder or use the correct relative path.
    * On some Windows/macOS systems, Docker Desktop may have a slight delay in syncing files back to the host. Wait a few seconds or check if the file appears after refreshing your file explorer.

- If you are building the image locally and see errors regarding `gcc`, `cc`, or `pycairo`:

    - Your Docker cache might be stale. Rerun the build with the `--no-cache` flag:
    ```bash
    docker build --no-cache -t kynetic-renderer .

    ```

- "Library not found" or "ffmpeg not found"
    * Ensure you are using the provided `Dockerfile`. This project requires specific system-level shared libraries (`.so` files) for Cairo and FFmpeg that are not included in standard Python environments.


### Locally via `poetry`

Install prerequisites:
- **Ubuntu/Debian:** `sudo apt install ffmpeg libcairo2-dev pkg-config python3-dev`
- **macOS:** `brew install ffmpeg cairo pkg-config`

Install dependencies:
```bash
poetry install
```

Render a project:
```bash
poetry run kynetic-render path/to/project.json
```
